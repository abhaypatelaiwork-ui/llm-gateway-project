# 🚀 LLM Gateway with Groq

A complete LLM Gateway demo using **LiteLLM + LangChain + Groq**.

## 📁 Project Structure
llm-gateway-project/
├── .env ← Add your GROQ_API_KEY here
├── requirements.txt
├── config.py ← Central config (models, routing)
├── llm_gateway.py ← Core gateway wrapper
├── examples/ ← Runnable demo scripts
